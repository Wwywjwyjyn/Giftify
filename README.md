# 🎁 Giftify — بازار گیفت، یوزرنیم و شماره تلگرام (شبیه فرگمنت)

سایت کامل و ریسپانسیو به سبک **Fragment.com** با تم خودِ فرگمنت (سرمه‌ای تیره) به‌علاوه **آبی نفتی** و
لوگوی نستعلیق «گیفتیفای» — متصل به **API مارکت‌اپ** (api.marketapp.org) برای:

| بخش | توضیح | وضعیت با توکن رایگان |
|---|---|---|
| یوزرنیم‌ها | جدول فرگمنتی + فیلتر + مرتب‌سازی + دکمه «اجاره کردن» روی هر ردیف | کالکشن‌ها ✓ — فید اجاره ✓ |
| شماره‌ها | شماره‌های +888 کلکسیونی + دکمه اجاره | فید اجاره ✓ |
| گیفت‌ها | گرید کارت با عکس واقعی فرگمنت + فیلتر کالکشن/قیمت/شماره + نمای جدول/کارت | فید اجاره ✓ |
| **اجاره (Rent)** | دکمه «اجاره کردن» روی ردیف‌ها + پنل مدت/پرداخت در صفحه آیتم + تاریخچه + اجاره‌های من | کامل و رایگان ✓ |
| **جستجوی فراگیر** | آیدی/کانال تلگرام (@، t.me)، آدرس NFT، کالکشن، گیفت، شماره +888 | کامل ✓ (t.me مستقیم) |
| **سبد خرید** | افزودن خریدها به سبد + پرداخت تراکنش‌به‌تراکنش + بج تعداد در هدر | کامل ✓ |
| **انباری (Inventory)** | خریدهای من + اجاره‌های فعال (واقعی از مارکت‌اپ) + اجاره‌دهی‌های من | کامل ✓ |
| استارز | خرید استارز با گیرنده واقعی و قیمت لحظه‌ای | کامل ✓ |
| پرمیوم | خرید اشتراک ۳/۶/۱۲ ماهه | کامل ✓ |
| گیوِی | گیوِی استارز (۱–۵ برنده) و پرمیوم (تا ۲۴۰۰۰) | کامل ✓ |
| تبلیغات | شارژ حساب Ads فرگمنت | کامل ✓ |
| آیتم | صفحه جزئیات: عکس واقعی، مدل/پس‌زمینه/نماد، اجاره کردن/خرید لیستینگ سایت | کامل ✓ |
| پنل مدیریت | کارمزد هر بخش + کیف پول کارمزد + سفارش‌ها + کاربران + لیستینگ محلی | کامل ✓ |

**نسخه ۲ — تغییرات این نسخه:**
- تم مشکی + توپ‌های ریزِ در حال حرکت در پس‌زمینه (انیمیشن GPU با احترام به `prefers-reduced-motion`)
- فونت‌های اینترنتی باندل‌شده: **Inter** (ارقام/لاتین مثل فرگمنت)، **Vazirmatn** (فارسی)، **Gulzar** (لوگوی نستعلیق)
- گزینهٔ «فروش» حذف شد؛ بازار = اجارهٔ رایگان مارکت‌اپ + لیستینگ‌های خود سایت
- دکمهٔ **«اجاره کردن»** روی همهٔ ردیف‌ها و کارت‌ها + پنل اجارهٔ کامل در صفحهٔ آیتم (حتی بدون پلن API، با کش RentCache)
- رفع کامل **لود نشدن عکس‌ها**: نگاشت دقیق slug فرگمنت برای ۴۰+ کالکشن + فال‌بک tonapi + تایل حرفی
- رفع **جستجوی آیدی و کانال**: صفحهٔ /search با خواندن مستقیم t.me (عنوان، عکس، تعداد مشترک)
- **سبد خرید** (localStorage) و **انباری** اضافه شد
- ریسپانسیو کامل موبایل: ۱۶px ورودی‌ها (ضد زوم iOS)، ناحیهٔ امن نوچ، بازخورد لمسی، بدون هایلایت خاکستری تپ
- اصول انیمیشن از مهارت‌های **emilkowalski/skills** (منحنی ease-out قوی، زیر ۳۰۰ms، فقط transform/opacity، stagger)

- **اولین کاربری که وارد سایت شود = مدیر** (اتصال کیف پول یا ورود تلگرام).
- کارمزد هر بخش جداگانه در پنل مدیریت تعیین می‌شود و به کیف پول TON ادمین پرداخت و **شفاف ثبت** می‌شود.
- همه پرداخت‌ها با **TON Connect** و امضای خود کاربر انجام می‌شود؛ سایت هیچ پولی را نگه نمی‌دارد.
- داخل تلگرام (Mini App) ورود **خودکار** است.

## ۱) اجرای محلی (تست)

```bash
# پیش‌نیاز: Node.js نسخه 18 به بالا
npm install
cp .env.example .env          # مقادیر را پر کنید (حداقل JWT_SECRET و MARKETAPP_API_TOKEN)
npx prisma db push            # ساخت دیتابیس SQLite
npm run dev                   # http://localhost:3000
```

برای حالت پروداکشن: `npm run build && npm start`

## ۲) توکن API مارکت‌اپ (مهم‌ترین قدم)

1. وارد **marketapp.org** شوید (با تلگرام).
2. از منو **API token** را باز کنید و توکن بگیرید.
3. در فایل `.env` بگذارید: `MARKETAPP_API_TOKEN="..."`

توکن فقط روی سرور استفاده می‌شود و هرگز به مرورگر فرستاده نمی‌شود.

**پلن رایگان چه چیزهایی می‌دهد؟** استارز، پرمیوم، گیوِی‌ها، تبلیغات، کالکشن‌ها و آمار، فید اجاره کامل،
فروش‌گذاری/تغییر قیمت/لغو فروش (تراکنش واقعی).
**پلن پولی (اختیاری):** فید فروش زنده (onsale)، خرید NFT و اطلاعات تک‌آیتم مارکت‌اپ. اگر 402 بدهد،
سایت به‌صورت خودکار به فید اجاره + لیستینگ‌های محلی برمی‌گردد و پیام شفاف نشان می‌دهد؛ با فعال‌کردن پلن
**بدون هیچ تغییر کد** همه‌چیز روشن می‌شود (وضعیت در `/api/health` و پنل مدیریت دیده می‌شود).

## ۳) اجرا روی هاست سی‌پنل (Setup Node.js App)

سی‌پنل اکثر هاست‌ها «Setup Node.js App» (با Passenger) دارد:

1. کل فایل‌های پروژه را در پوشه اپ آپلود/اکسترکت کنید (مثلاً `giftify/`).
2. در سی‌پنل → **Setup Node.js App** → Create Application:
   - Node.js version: حداقل **18** (بهتر: 20 یا 22)
   - Application mode: **Production**
   - Application root: `giftify`
   - Application URL: دامنه/زیردامنه شما
   - **Application startup file: `server.js`** ← مهم
3. وارد محیط مجازی اپ شوید (دکمه «Run NPM Install» یا ترمینال):
   ```bash
   npm install
   cp .env.example .env   # و مقادیر را پر کنید
   npx prisma db push
   npm run build
   ```
4. در همان صفحه Node.js App روی **Restart** بزنید. سایت بالا می‌آید.
5. SSL رایگان (Let's Encrypt) را از بخش SSL/TLS فعال کنید — لازم است (برای TON Connect و Mini App).

نکته‌ها:
- دیتابیس در `prisma/dev.db` ساخته می‌شود؛ از آن **بک‌آپ دوره‌ای** بگیرید.
- اگر هاست شما Node ندارد، از داکر/دیپلکسو استفاده کنید.

## ۴) اجرای رایگان روی دیپلکسو (deplexo.com)

دیپلکسو اپ‌های Node و Dockerfile را از گیت اجرا می‌کند:

1. پروژه را به GitHub/GitLab/Bitbucket/Codeberg پوش کنید.
2. در **deplexo.com** با گیت لاگین کنید → New App → مخزن `giftify` را انتخاب کنید.
3. دیپلکسو خودش تشخیص می‌دهد (Node) یا از `Dockerfile` می‌سازد؛ Environment Variables را اضافه کنید:
   `JWT_SECRET`، `MARKETAPP_API_TOKEN`، `TELEGRAM_BOT_TOKEN`، `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME`، `NEXT_PUBLIC_SITE_NAME`
4. Deploy → بعد از healthcheck، سایت با زیردامنه HTTPS بالا می‌آید.
5. دامنه دلخواه هم می‌توانید وصل کنید.

> توصیه برای دیپلکسو: مسیر `Dockerfile` (پیش‌فرض پروژه) پایدارتر است؛ دیتابیس روی volume ذخیره می‌شود.

## ۵) اجرا با داکر (روی هر سرور)

```bash
JWT_SECRET="...64 کاراکتر تصادفی..." MARKETAPP_API_TOKEN="..." docker compose up -d --build
```

## ۶) تبدیل به Telegram Mini App

1. در `.env` مقدار `TELEGRAM_BOT_TOKEN` (از BotFather) و `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME` را بگذارید.
2. در BotFather → `/newapp` → ربات را انتخاب کنید → آدرس سایت را بدهید (برای `/`).
3. حالا داخل تلگرام، باز کردن اپ باعث **ورود خودکار** می‌شود (بر اساس امضای initData تلگرام).

## ۷) پنل مدیریت (اولین نفر = مدیر)

- وارد سایت شوید و «اتصال کیف پول» بزنید (یا داخل تلگرام وارد شوید). **اولین کاربر** نقش ADMIN می‌گیرد.
- در `/admin`:
  - **کارمزدها:** درصد کارمزد هر بخش + **کیف پول TON دریافت کارمزد**.
  - **سفارش‌ها و کارمزد:** همه خریدها و ردیف کارمزدها با وضعیت پرداخت (شفاف).
  - **کاربران:** ارتقا/سلب مدیریت.
  - **لیستینگ محلی:** آیتم‌های خودتان را (فروش یا اجاره) به بازار اضافه کنید؛ پرداخت خرید مستقیم به
    کیف پول شما + کارمزد سایت در **یک تراکنش** انجام می‌شود.
- اعلان صفحه اصلی هم از همان‌جا قابل تنظیم است.

## ۸) شفافیت کارمزد و پرداخت‌ها

- خرید استارز/پرمیوم/گیوِی/تبلیغات: قیمت لحظه‌ای از فرگمنت (از طریق مارکت‌اپ) دریافت و تراکنش امضانشده
  به کیف پول کاربر داده می‌شود؛ کاربر با کیف پول خودش امضا می‌کند. کارمزد سایت جداگانه و آشکار نمایش
  داده و در پنل ثبت می‌شود.
- **محدودیت مارکت‌اپ:** تراکنش‌های خرید باید با همان کیف پولی امضا شوند که توکن API با آن ساخته شده است.
  پس برای خریدها، مدیر همان کیف پول را وصل می‌کند (یا از فلو مستقیم لیستینگ محلی استفاده کنید).
- خرید لیستینگ‌های محلی سایت: یک تراکنش با دو خروجی (پول فروشنده + کارمزد به کیف ادمین) — کاملاً آن‌چین و شفاف.

## ۹) عکس‌های گیفت‌ها (سه لایه — هیچ‌وقت خالی نمی‌ماند)

1. **الگوی رسمی فرگمنت** `nft.fragment.com/gift/{slug}-{num}.webp` — slug از نام آیتم با نگاشت دقیق ۴۰+ کالکشن
   (`src/lib/giftimg.ts`) ساخته می‌شود؛ بدون حتی یک درخواست سرور.
2. **پراکسی `/api/img/{address}`** → tonapi.io (متادیتای واقعی NFT) برای کالکشن‌های ناشناخته/یوزرنیم‌ها/شماره‌ها.
3. **تایل متنی** با حرف اول — در بدترین حالت هم ظاهر تمیز می‌ماند.

## ۱۰) نکات امنیتی

- `JWT_SECRET` را حتماً عوض کنید و `.env` را هرگز در گیت پوش نکنید (`.gitignore` آماده است).
- توکن مارکت‌اپ فقط سمت سرور است (متغیر محیطی).
- ورود کیف پول در صورت وجود `ton_proof` با امضای دیجیتال تأیید می‌شود؛ در غیر این صورت کاربر فقط
  «وارد‌شده» ثبت می‌شود — برای سایت شخصی خودتان کافی است، اما اگر سایت عمومی می‌کنید توصیه می‌شود
  از ورود تلگرام (امضاشده) به‌عنوان مرجع مدیریت استفاده کنید.
- هیچ داده دمویی در هیچ فایلی نیست؛ همه‌چیز واقعی از API خوانده می‌شود.

## ۱۱) ساختار پروژه

```
giftify/
├─ prisma/schema.prisma          # دیتابیس (SQLite)
├─ server.js                     # نقطه ورود سی‌پنل (Passenger)
├─ Dockerfile + docker-compose   # داکر/دیپلکسو
├─ public/                       # فونت‌ها (Gulzar نستعلیق + Vazirmatn) و آیکون‌ها
└─ src/
   ├─ app/                       # صفحات: / , numbers, gifts, rent, search, cart, inventory, stars(+buy), premium, giveaway, ads, item, login, admin, my
   ├─ app/api/                   # auth | market | fragment | rent | search | orders | admin | inventory | health | img
   ├─ components/                # هدر (سبد+انباری)، جدول فرگمنتی، گرید، توست‌ها، پس‌زمینه متحرک، جریان خرید، پنل ادمین...
   └─ lib/                       # marketapp client, market data layer, auth (اولین کاربر=مدیر), ton proof, تلگرام, تنظیمات
```
